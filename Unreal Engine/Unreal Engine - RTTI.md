## 1. 한 줄 요약
RTTI (Runtime Type Information)는 런타임에 객체의 타입을 식별하고 정보를 얻을 수 있는 메커니즘이다.

## 2. 왜 필요한가? (Why)
- 런타임에 객체 타입 확인
- 다형성 구현
- 안전한 타입 캐스팅

## 3. 핵심 개념 (What)
- `dynamic_cast`, `typeid` 연산자 사용
- 클래스 계층 구조 정보 제공
- 런타임 타입 검사

## 4. 동작 과정 (How)
1.  `dynamic_cast`: 런타임에 타입 변환 시도, 실패 시 `nullptr` 반환
2.  `typeid`: 객체의 `type_info` 객체 반환

## 5. 장단점 / 트레이드오프
- 장점: 런타임 타입 안정성 확보, 다형성 활용
- 단점: 성능 오버헤드 발생 가능성, 코드 복잡성 증가

## 6. 자주 나오는 질문 / 오해
- Q: RTTI 를 사용하지 않고 다형성을 구현할 수 있는가?
- A: 템플릿 메타 프로그래밍 등 다른 방법 존재

## 7. 프로젝트에서 어디에 쓰일 수 있는가
- 게임 오브젝트 타입에 따른 동작 분기
- 에디터 기능 확장
- 시리얼라이제이션
