## 1. 한 줄 요약
DLL (Dynamic Link Library)은 동적으로 링크되는 라이브러리로, 코드 재사용성 및 모듈화를 통해 효율적인 개발 환경을 제공한다.

## 2. 왜 필요한가? (Why)
- 코드 재사용성 증대
- 모듈화된 개발 가능
- 실행 파일 크기 감소
- 업데이트 용이성 향상

## 3. 핵심 개념 (What)
- 동적 링크: 프로그램 실행 시점에 라이브러리 연결
- 코드 및 데이터 공유
- API (Application Programming Interface) 제공

## 4. 동작 과정 (How)
1.  프로그램 실행 시, 필요한 DLL 로드
2.  DLL 내의 함수 호출
3.  DLL 과 프로그램 간의 데이터 교환

## 5. 장단점 / 트레이드오프
- 장점: 코드 재사용성, 모듈화, 실행 파일 크기 감소
- 단점: DLL 관리 복잡성, 의존성 문제 발생 가능성

## 6. 자주 나오는 질문 / 오해
- Q: DLL Hell 이란 무엇인가?
- A: DLL 버전 충돌로 인해 발생하는 문제

## 7. 프로젝트에서 어디에 쓰일 수 있는가
- 엔진 기능 확장
- 플러그인 개발
- 외부 라이브러리 통합
