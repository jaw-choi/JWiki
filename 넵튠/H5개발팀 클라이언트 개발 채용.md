## 작성 글
### 자기소개 (이력서 자기소개 항목, 자유 양식)
*(870자 / 제한 1000자)*

Unity로 만든 게임을 실제 스토어에 출시하고, 낯선 코드와 SDK를 연결해 동작하게 만든 경험을 넵튠 H5 개발팀에서 살리고 싶어 지원합니다. 저는 2인 팀으로 Unity 모바일 게임 눈덩이를 굴려라를 개발해 Google Play와 App Store에 출시했습니다. UI Toolkit과 ScriptableObject로 화면과 데이터를 나눴고, Firebase와 AdMob SDK를 연동했으며, 플랫폼마다 다른 빌드 설정과 심사 요건을 놓치지 않도록 릴리즈 체크리스트를 만들어 출시까지 관리했습니다. 이 경험은 여러 서비스 플랫폼 출시를 위한 SDK 연동과 환경별 대응 업무와 직접 맞닿아 있습니다. WebGL 포팅에 필요한 그래픽스 이해도 갖추고 있습니다. OpenGL로 디퍼드 셰이딩과 큐브맵 반사를 구현한 Shading Project와, C++와 OpenGL 자체 엔진으로 만든 BIT SAVER를 통해 렌더링 파이프라인이 어떻게 동작하는지 직접 다뤘습니다. 기존 코드를 분석하고 이식하는 힘은 자체 엔진 프로젝트에서 길렀습니다. 4인 팀 Project GGD에서 자체 엔진 JinEngine 위에 디펜스 게임의 게임플레이를 맡아 유닛 합성, 웨이브 스킵, 바이너리 저장을 구현했고, 엔진 구조를 먼저 읽은 뒤 기능을 붙이는 방식으로 일했습니다. 언리얼 엔진 5.6과 GAS로 만든 5인 팀 프로젝트 LTF에서는 타일 조회를 평균 O(1)로 개선하며 성능 문제를 해결해 최종 1위를 했습니다. 미국 A Round Entertainment 인턴으로 출시 앱 JOOPI를 React Native로 개발하며 웹 기술 기반 개발에도 익숙합니다. Cocos Creator는 빠르게 익혀, 넵튠의 히트작들이 더 많은 플랫폼에서 이용자를 만나도록 돕겠습니다.
