### 자유 양식 자기소개
*(917자 / 제한 1000자)*

운전 중에도 말 한마디로 길 안내와 음악, 차량 기능을 다루는 AI Agent는 제가 SeSAC 과정에서 만들어 본 서비스와 가장 가까운 문제입니다. 저는 팀 프로젝트 AI 비서에서 에이전트와 음성 기능을 맡아, 호출어 감지부터 음성 인식, 도구 선택, 실행 결과의 음성 응답까지 이어지는 흐름을 구현했습니다. 이 비서는 19개 도구를 호출하는데, 모든 요청을 LLM에 맡기면 정확하지만 느리고 토큰 비용이 컸고, 규칙만 쓰면 빠르지만 자주 틀렸습니다. 저는 감에 의존하지 않기 위해 69개 평가 문장을 만들어 같은 기준으로 비교했고, 규칙 기반 78%, LLM 단독 88%라는 결과에서 두 방식이 틀리는 문장의 유형이 다르다는 점을 찾았습니다. 그래서 명확한 명령은 규칙으로 바로 처리하고 모호한 요청만 LLM으로 넘기는 하이브리드 라우팅을 설계해 정확도 91%를 달성하고, LLM 단독 대비 처리 시간과 토큰을 약 60% 줄였습니다. 공고에서 말하는 프롬프트와 모델 라우팅 전략 최적화, 평가 데이터셋 기반의 품질 개선은 제가 직접 겪으며 가장 많이 배운 부분입니다. 또한 미국 스타트업의 원격 인턴으로 App Store에 출시된 앱 JOOPI의 프로필 편집과 Firebase 실시간 동기화를 구현하며 실제 사용자가 쓰는 서비스의 무게를 경험했고, Unity 게임 눈덩이를 굴려라를 Google Play와 App Store에 직접 출시하며 출시 전 점검의 중요성도 배웠습니다. 현재 SeSAC에서 FastAPI 기반 백엔드와 LangChain, LangGraph, MCP를 배우고 있고, 과정 후반에는 Docker, Kubernetes, AWS를 익힐 예정입니다. 입사 후에는 멀티턴 대화와 Tool Calling 기능을 평가 데이터로 검증하며 개선하는 일부터 맡아, 운전자가 믿고 쓰는 TMAP Agent를 만드는 데 기여하겠습니다.
