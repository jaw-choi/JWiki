### [예상] 1. 지원하신 직무 분야의 전문성을 키우기 위해 꾸준히 노력한 경험에 대해 서술해주세요.
*(559자 / 제한 600자)*

그래픽스와 엔진 프로그래밍을 꾸준히 공부하며 장면을 데이터로 표현하는 역량을 키웠습니다. DigiPen 컴퓨터공학(RTIS) 과정에서 OpenGL로 Shading Project를 진행하며 G-Buffer MRT 기반 디퍼드 셰이딩, 큐브맵 반사, 레이 트레이싱을 직접 구현했고, ImGui 디버그 뷰로 각 버퍼를 눈으로 확인하며 렌더링 결과가 어떤 기하·재질 정보에서 만들어지는지 분석했습니다. 4인 팀의 Tech Lead로 C++/OpenGL 자체 엔진 게임 BIT SAVER를 만들었고, 최근에는 C++ 자체 엔진 JinEngine 기반 Project GGD에서 게임플레이를 맡고 있습니다. 렌더링이 장면을 이미지로 만드는 과정이라면, 장면 재구성과 Inverse Rendering은 그 반대 방향이라는 점에 끌렸습니다. 이를 위해 SeSAC AI 서비스·클라우드 과정에서 LLM, RAG, 에이전트를 배우며 AI 모델을 서비스에 연결하는 방법을 익히고 있습니다. 3D Reconstruction과 Neural Rendering은 그래픽스 기초 위에서 논문과 공개 구현으로 이어서 공부하겠습니다.

### [예상] 2. 팀워크를 발휘해 사람들을 연결하고 공동 목표 달성에 기여한 경험에 대해 서술해주세요.
*(527자 / 제한 600자)*

원티드 게임 개발 과정의 5인 팀 프로젝트 LTF(언리얼 엔진 5.6, GAS)에서 전투와 스킬 시스템을 맡아 최종 1위를 했습니다. 개발 후반, 여러 유닛이 동시에 이동을 판단하면서 빈 타일이 있어도 예약 정보가 얽혀 이동이 멈추는 버그가 반복됐습니다. 각 유닛이 따로 판단하던 구조라 원인이 한 사람의 코드에 있지 않았습니다. 저는 전투 매니저가 타일의 점유와 예약 상태를 중앙에서 관리하도록 구조를 바꾸자고 제안했고, 이동과 스킬을 맡은 코드가 같은 상태를 보도록 맞췄습니다. 또 선형 탐색이던 타일 조회를 거리 캐시와 해시 조회로 바꿔 평균 O(1)로 개선하고, 서버와 클라이언트의 FX 처리를 분리해 각자의 작업이 서로를 막지 않게 했습니다. 그 결과 이동 정체가 사라졌고 팀은 남은 기간을 콘텐츠 완성도에 쓸 수 있었습니다. 문제를 개인의 실수가 아닌 구조의 문제로 보고 모두가 같은 기준으로 일하도록 연결하는 것이 팀워크라고 배웠습니다. SK인텔릭스에서도 연구 결과가 로봇 시스템과 맞물리도록 동료들과 인터페이스부터 맞추겠습니다.

> [확인 필요] '구조 변경을 제안하고 이동·스킬 코드가 같은 상태를 보도록 맞췄다', '남은 기간을 콘텐츠 완성도에 썼다'는 부분은 실제 진행과 같은지 확인해 주세요.

### [예상] 3. 도전적인 목표를 세우고 성취하기 위해 끈질기게 노력한 경험에 대해 서술해 주세요.
*(515자 / 제한 600자)*

SeSAC 팀 프로젝트 'AI 비서'에서 에이전트의 정확도와 응답 속도를 함께 높이는 것을 목표로 세웠습니다. 19개 도구를 호출하는 에이전트에서 모든 요청을 LLM에 맡기면 정확하지만 느리고, 규칙만 쓰면 빠르지만 자주 틀렸습니다. 어느 한쪽을 포기하지 않기 위해 먼저 69개 평가 문장을 만들어 같은 기준으로 비교할 수 있게 했습니다. 규칙 기반은 78%, LLM 단독은 88%의 정확도를 보였고, 두 방식이 틀리는 문장의 유형이 다르다는 점을 확인했습니다. 그래서 명확한 명령은 규칙으로 바로 처리하고 모호한 요청만 LLM으로 넘기는 하이브리드 라우팅을 설계했고, 평가 문장으로 결과를 반복 검증하며 기준을 다듬었습니다. 최종적으로 정확도 91%를 달성했고, LLM 단독 대비 처리 시간과 토큰을 약 60% 줄였습니다. 목표가 어려울수록 감이 아닌 측정 기준을 먼저 세워야 끝까지 개선할 수 있다는 것을 배웠습니다. 장면 재구성 연구에서도 재구성 품질을 정량 지표로 먼저 정의하고, 그 지표로 개선을 반복하겠습니다.

### 포트폴리오 구성안 (본인이 대표 참여자인 프로젝트)
1. Shading Project (OpenGL, 개인) — G-Buffer MRT·디퍼드 셰이딩·큐브맵 반사·레이 트레이싱, ImGui 버퍼 시각화 화면 (장면 표현·렌더링 방정식 이해 → Inverse Rendering 연결)
2. BIT SAVER (C++/OpenGL 자체엔진, 4인, Tech Lead) — 엔진 구조, FMOD MIDI 파싱, Arduino 드럼 패드 (하드웨어 연동)
3. Project GGD / JinEngine (C++ 자체 엔진) — Gameplay, 바이너리 저장 구조
4. AI 비서 (SeSAC) — 평가 데이터 기반 하이브리드 라우팅 91%, 약 60% 감소 (정량 평가 방법론)
