### 사람인 이력서 자기소개서 (자유 양식, 1,000자 기준)
*(935자 / 제한 1000자)*

레저 상품 판매와 결제처럼 실제 매출이 오가는 서비스를 FastAPI 백엔드와 AI 자동화로 함께 다룰 수 있다는 점에 끌려 지원했습니다. 저는 여러 스택을 오가며 제품을 끝까지 만들어 본 개발자입니다. 미국 스타트업 인턴으로 App Store에 출시된 데이팅 앱 JOOPI의 프로필 편집, 이미지 업로드, Firebase 실시간 동기화를 React Native로 구현했고, 2인 팀으로 Unity 모바일 게임을 Google Play와 App Store에 출시하며 릴리즈 체크리스트와 광고 연동, 스토어 정책 대응까지 맡았습니다. SeSAC 과정 팀 프로젝트에서는 FastAPI 기반 AI 비서의 에이전트를 맡아 명령 API 클라이언트의 로그인·토큰 재발급 흐름을 만들고, 69개 평가 문장으로 라우팅 방식을 비교해 LLM 단독 대비 처리 시간과 토큰을 약 60% 줄였습니다. 이 경험은 오픈마켓 주문 수집이나 공급사 API 연동처럼 외부 시스템과 데이터를 안정적으로 주고받는 일에도 그대로 쓰인다고 생각합니다. AI는 구조를 먼저 설계한 뒤 제가 설명할 수 있는 코드만 적용하는 원칙으로 활용합니다. 원티드 게임 개발 과정에서 언리얼 엔진 5.6과 GAS 기반 5인 팀 프로젝트 LTF(오토배틀러)를 진행해 최종 1위를 했습니다. 전투·스킬 시스템을 맡아 20종 이상의 챔피언 스킬과 공격 파이프라인을 구현했는데, 여러 유닛이 동시에 이동을 판단하면서 빈 타일이 있어도 예약 정보가 얽혀 이동이 멈추는 버그가 반복됐습니다. 각 유닛이 따로 판단하던 구조를 전투 매니저가 점유·예약 상태를 중앙에서 관리하는 구조로 바꾸고, 선형 탐색이던 타일 조회를 거리 캐시와 해시 조회로 바꿔 이동 정체와 유닛 수에 비례하던 계산량 문제를 함께 해결했습니다. 신기술에 빠르게 대응한다는 플레이스토리의 방향처럼, AI 기반 개발 자동화 워크플로우를 팀에 정착시키는 개발자가 되겠습니다.
