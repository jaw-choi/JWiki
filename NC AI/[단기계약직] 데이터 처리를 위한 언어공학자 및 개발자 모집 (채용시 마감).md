### 자유 양식 자기소개
*(911자 / 제한 1000자)*

AI 모델의 성능은 결국 데이터의 품질에서 결정된다는 것을 SeSAC AI 서비스 클라우드 과정의 팀 프로젝트에서 직접 체감했습니다. 저는 노트북용 AI 비서에서 에이전트와 음성 기능을 맡아 19개 도구를 호출하는 구조를 만들었습니다. 처음에는 프롬프트를 고칠 때마다 결과가 나아졌는지 감으로 판단했고, 같은 수정이 어떤 요청에서는 좋아지고 다른 요청에서는 나빠지는 일이 반복됐습니다. 그래서 69개 평가 문장을 직접 만들어 모든 방식을 같은 기준으로 비교했습니다. 이 평가 데이터 덕분에 규칙 기반 78%, LLM 단독 88%라는 기준선을 숫자로 확인했고, 두 방식이 틀리는 문장의 유형이 서로 다르다는 점도 드러났습니다. 이를 근거로 명확한 명령은 규칙으로, 모호한 요청만 LLM으로 보내는 하이브리드 라우팅을 설계해 정확도 91%를 달성하고, LLM 단독 대비 처리 시간과 토큰을 약 60% 줄였습니다. 이 경험으로 데이터의 분류 기준과 평가지표를 먼저 설계해야 모델 개선이 반복 가능해진다는 것을 배웠습니다. NC AI 데이터 조직이 하는 데이터 수집, 분석, 증강, 평가 자동화는 제가 작은 규모로 해 본 일을 대용량으로 넓히는 일이라고 생각해 지원했습니다. 또한 팀원 모듈과 Electron 화면을 연결하는 인터페이스를 정리하며, 여러 사람이 같은 데이터 형식을 쓰도록 맞추는 일이 품질의 출발점이라는 것도 배웠습니다. 저는 Python으로 에이전트와 평가 코드를 작성해 왔고, 정보처리기사와 ADsP를 취득하며 데이터 처리와 분석의 기초도 다졌습니다. 또한 C++ 자체 엔진 개발 경험으로 대량의 데이터를 다룰 때 성능과 구조를 함께 고민하는 습관을 갖췄습니다. 입사 후에는 데이터 처리 파이프라인을 안정적으로 운영하는 일부터 맡아, 데이터 유형별 품질 지표와 평가 자동화가 팀의 공통 기준이 되도록 기여하겠습니다.

> [확인 필요] 프롬프트를 고칠 때마다 감으로 판단했다는 초기 상황 묘사, Python으로 평가 코드를 작성했다는 부분이 실제와 같은지 확인해 주세요.
