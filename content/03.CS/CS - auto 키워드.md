
## 1. 한 줄 요약

`auto` 키워드는 변수의 자료형을 컴파일러가 자동으로 추론하도록 하는 기능이다.

## 2. 왜 필요한가? (Why)

- 코드 간결성 향상
- 템플릿 코드 작성 용이
- 자료형 명시의 번거로움 감소

## 3. 핵심 개념 (What)

- 컴파일 타임 자료형 추론
- 초기화 값을 통해 자료형 결정

## 4. 동작 과정 (How)

1. `auto` 키워드를 사용하여 변수 선언
2. 컴파일러가 초기화 값을 통해 자료형 추론

## 5. 장단점 / 트레이드오프

- 장점:
    - 코드 간결성 향상
    - 템플릿 코드 작성 용이
- 단점:
    - 코드 가독성 저하 가능성 (남용 시)
    - 컴파일 시간 증가 가능성

## 6. 자주 나오는 질문 / 오해

- Q: `auto` 키워드는 런타임 성능에 영향을 미치는가?
- A: 컴파일 타임에 자료형이 결정되므로 런타임 성능에는 영향 없음

## 7. 프로젝트에서 어디에 쓰일 수 있는가

- 템플릿 코드 작성
- 복잡한 자료형을 간단하게 표현
- 코드 간결성 향상
