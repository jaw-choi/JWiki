## 1. 위치(Position)와 벡터(Vector)의 개념 구분

- **위치 + 위치**  
    → 수학적·엔진 개념상 의미 없음 (정의되지 않음)
    
- **위치 − 위치**  
    → 방향과 크기를 가진 **벡터**가 생성됨
    
- **위치 + 벡터**  
    → 새로운 **위치**가 생성됨 (이동의 본질)
    
- 게임 엔진에서 이동이란  
    → 위치에 **방향·힘(벡터)** 을 더하는 행위
    
- 따라서 모든 이동 로직은  
    → Position + Direction(Vector) 구조로 구성됨
## 2. 차원 확장과 동차 좌표 개념

- 2D → 3D → 4D 개념으로 확장
    
- 내부적으로는
    
    - 위치: 마지막 성분이 1
        
    - 방향(벡터): 마지막 성분이 0
        
- 이를 통해
    
    - 위치 + 벡터 = 위치
        
    - 위치 + 위치 불가  
        논리가 성립됨
