#### 오전 
다루신 내용은 크게 2파트입니다. 과제 안내, 그리고 알고리즘/난수(랜덤) 강의 요약입니다.

1. 과제 안내 요약
    

- 방식
    
    - 제공된 문제 페이지에 직접 쓰는 게 아니라, 본인 페이지에 새 페이지를 만들고 문제를 복사해서 붙여넣은 뒤 답안을 작성
        
    - 답안은 출력값 예측 + 이유 설명, 왜 잘못된 동작이 발생하는지/올바르게 고치는 법까지 설명하는 형태
        
    - 완료 후 댓글(또는 지정된 방식)로 답안 공유 + 깃허브 링크 제출
        
- C++ 퀴즈에서 요구하는 설명 주제들
    
    - 형변환이 되면 안 되는데 되는 코드가 왜 그런지, 제대로 막으려면 어떻게 해야 하는지
        
    - static 키워드의 역할과 동작 방식, 그리고 출력 결과 예측
        
    - 다운캐스팅을 왜 함부로 쓰면 안 되는지
        
    - dynamic_cast 대신 커스텀 RTTI를 왜 구현하는지
        
    - weak_ptr을 왜 쓰는지, shared_ptr로는 왜 부족한지, lock을 왜 쓰는지
        
- 자료구조 실습
    
    - 선형 자료구조 실습 3문제
        
    - 비선형 자료구조는 BST 기반 랭킹 퀴즈 성격이며, CSV를 파싱해서
        
        - 하나는 이진 탐색 트리에 저장
            
        - 다른 하나는 해시 테이블에 저장
            
    - 택 1 가능하지만 가능하면 둘 다 권장
        

2. 알고리즘 분석(빅오) 요약
    

- 빅오 표기법은 정확한 측정이 아니라 대략적인 추정 도구
    
    - 상수항 제거, 저차항 제거, 최고차항만 남기는 이유는 n이 커질수록 지배항만 의미가 커지기 때문
        
    - O(c)와 O(1)은 같은 의미(상수 시간)
        
    - O(n)에서 앞의 계수(2n, 3n 등)는 보통 무시하고 n만 본다
        
- 최선보다 평균/최악에 집중
    
    - 현실에서는 최선은 드물어서, 최악을 가정해 감당 가능한지로 의사결정하는 게 실용적
        
- 실전 성능 판단은 측정이 가장 확실
    
    - 타이머로 실제 병목을 확인하고 최적화는 계산을 덜 하게 만드는 방향으로 접근
        

3. 이진 탐색 요약
    

- 전제 조건: 정렬된 배열/리스트에서만 신뢰 가능
    
- 동작: 중간값 기준으로 탐색 범위를 절반씩 줄임
    
- 주의: 정렬이 안 된 데이터를 이진 탐색하려면 정렬 비용이 먼저 발생하므로, 무조건 빠른 선택은 아님
    

4. 난수(rand/srand/time) 강의 요약
    

- rand는 결정론적
    
    - 같은 실행 조건에서 호출 횟수가 같으면 같은 값이 나온다
        
- srand로 시드(seed, 종작값)를 줘야 난수처럼 보이기 시작
    
    - 단, srand(100)처럼 고정 시드는 실행할 때마다 동일 패턴
        
    - 실행마다 바뀌는 시드가 필요하고 대표가 time 기반 시드
        
- 호출 규약 언급(추가 키워드)
    
    - cdecl: 호출자(caller)가 스택 정리
        
    - stdcall: 피호출자(callee)가 스택 정리
        
    - 시스템/운영체제 쪽 질문에서 키워드로 나올 수 있음
        
- rand 범위
    
    - RAND_MAX가 있고(예시로 32767), 기본 rand는 0~RAND_MAX 범위
        
- 원하는 정수 범위 만들기
    
    - 나머지 방식: (rand() % range) + min
        
        - 단점: 하위 비트만 쓰는 성격이라 분포/주기 품질이 나빠질 수 있음
            
    - 나누기 기반(0~1 실수로 만든 뒤 스케일)
        
        - randomPercent = float(rand()) / RAND_MAX → 0~1
            
        - randomRangeFloat = min + (max - min) * randomPercent
            
        - 이 방식이 엔진(언리얼 등) 코드에서도 유사하게 쓰인다
            
- 실전 활용 감각
    
    - 0~1 랜덤을 만든 뒤 스케일/오프셋(범위 확대 + 최소값 보정)하는 패턴은
        
        - AI 이동 지점 랜덤 선택, 카메라 흔들림, 셰이더 노이즈 등에서 매우 자주 등장
            
- 비선형 난수(분포 바꾸기) 아이디어
    
    - 난수를 여러 번 뽑아 더하면 분포가 중앙에 몰리는 형태로 바뀜
        
    - 특정 구간이 더 잘 나오게/덜 나오게 확률 성형할 때 활용 가능(가차 같은 확률 설계 예시)
