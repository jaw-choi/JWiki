엔진 Gemini 분석


  엔진 및 게임 흐름 분석

   1. 프로그램 시작 (`Game/Main.cpp`):
       * main 함수가 Game 객체를 생성하고 game.Run()을 호출하여 게임을 시작합니다.

   2. `Game` 클래스 (`Game/Game.cpp`):
       * Game 클래스는 Engine을 상속받습니다.
       * 생성자에서 SokobanLevel과 MenuLevel을 생성하여 levels라는 벡터에 저장합니다.
       * Engine의 mainLevel을 SokobanLevel로 설정하여 게임 플레이부터 시작하도록 합니다.
       * ToggleMenu() 함수로 게임 플레이와 메뉴 화면을 전환할 수 있습니다.

   3. `Engine` 코어 (`Engine/Engine.cpp`):
       * Engine::Run() 메소드에 메인 게임 루프가 있습니다.
       * 루프는 다음 작업을 반복합니다.
           * 입력 처리: input->ProcessInput()
           * 로직 업데이트: Tick(deltaTime) -> 현재 mainLevel의 Tick()을 호출하여 모든 액터(캐릭터, 벽 등)의 상태를
             업데이트합니다.
           * 화면 그리기: Draw() -> 현재 mainLevel의 Draw()를 호출하여 화면을 그립니다.
       * SetNewLevel() 함수는 현재 레벨을 삭제하고 새로운 레벨로 교체합니다.

   4. `Level` 및 `Actor`:
       * Level은 Actor(게임 내 모든 객체)를 담는 컨테이너입니다.
       * SokobanLevel에 실제 게임 로직이 들어있습니다.
       * SokobanLevel::LoadMap()은 Stage1.txt 같은 맵 파일을 읽어 Player, Wall, Box 등의 액터를 생성합니다.
       * SokobanLevel::CanMove() 안에서 CheckGameClear()를 호출하여 게임 클리어 조건을 확인합니다.
       * CheckGameClear()는 모든 박스가 목표 지점에 도달했는지 검사합니다.
       * 조건이 만족되면 isGameClear 변수가 true가 되고, SokobanLevel::Draw()에서 "Game Clear!" 메시지를 화면에
         출력합니다.
