- 플레이어 스테이트
  - 플레이어 관련 데이터 처리 객체

|데이터 종류|두기 좋은 곳|이유|
|---|---|---|
|로그인 상태, 서버 접속 정보, 전역 설정|`GameInstance`|맵이 바뀌어도 유지돼야 함|
|한 판의 룰, 스폰 규칙, 승리 조건|`GameMode`|매치 단위 규칙을 담당|
|경기 시간, 현재 라운드, 팀 점수|`GameState`|모든 클라이언트가 공유해야 함|
|플레이어 입력 처리, 카메라, Possess 대상|`PlayerController`|플레이어의 제어 주체|
|플레이어 닉네임, 킬 수, 팀 번호|`PlayerState`|다른 플레이어에게도 보여야 함|
|이동, 충돌, 실제 월드 위치|`Pawn` / `Character`|월드에서 움직이는 실체|
|재사용 가능한 기능 단위|`Component` / `Subsystem`|상속보다 분리와 재사용에 유리|

게임 플레이 시작 시
1. 게임 모드 로드
2. 게임 모드에 설정된 각 클래스 객체 생성
3. 폰 생성/플레이어 컨트롤러 생성
4. 빙의(Possess, 소유) -> 컨트롤러가 기본 폰을 소유
5. 게임 준비(입력 받을 준비 등)
