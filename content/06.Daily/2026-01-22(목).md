매개 변수로 const int x 인데 사실 const int const x 무슨의미?

- x 가 const 인 int로 선언되었기 때문에 const x 안해도 상관 x

2.
inline int GetX() const 
{
    return x;
}
게터에서 inline과 const 무슨의미
- inline은 중복 정의 허용,다중 정의x, 최적화,함수 호출 비용 없앰->함수호출 대신 그 함수 본문으로 그대로 치환해버림
- 끝의 const 이 함수가 객체 상태를 바꾸지 않는다 라는 약속
	- 또한 const 객체 호출 가능해짐
