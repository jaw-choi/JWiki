```c++
이후 input 에 아래 함수의 if(!initialized) 안에 구문들이 레벨이 바뀌면 정상적으로 다시 동작됨. 이전에는 메뉴레벨끝나면 다시 안들어와서 메인레벨에서 마우스 관련 인풋이 안들어왔던거였음!
void Input::ProcessInput()
{
	// 입력 핸들 얻어오기 & 마우스 입력 활성화 설정.
	static HANDLE inputHandle = GetStdHandle(STD_INPUT_HANDLE);

	if (!initialized)
	{
		// 마우스 이벤트 활성화.
		DWORD mode = ENABLE_MOUSE_INPUT | ENABLE_EXTENDED_FLAGS;
		mode &= ~ENABLE_QUICK_EDIT_MODE;
		BOOL result = SetConsoleMode(inputHandle, mode);

		// 설정 실패한 경우 예외처리.
		if (result == FALSE)
		{
			// 오류 메시지 출력.
			MessageBoxA(
				nullptr, 
				"Input::ProcessInput() - Failed to set console mode", 
				"Error", 
				MB_OK
			);
			__debugbreak();
		}

		initialized = true;
	}
```
