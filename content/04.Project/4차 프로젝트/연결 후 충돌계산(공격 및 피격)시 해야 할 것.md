연결 후
플레이어 충돌 구현 후 연결 방법

  실제 피격 충돌이 생기면 플레이어 공격 히트 이벤트에서 이 두 줄만 추가하면 됩니다:

  // 일반 공격 히트 시
  BB->SetValueAsBool(TEXT("IsBeaten"), true);  // (선택사항, Beaten은 즉각반응이라 BB 없이도 가능)
  Toad->PlayBeatenByAI(false, Delegate);

  // 강공격 히트 시
  Toad->PlayBeatenByAI(true, Delegate);

  // 패링 성공 시
  BB->SetValueAsBool(TEXT("IsStunned"), true);
  // BTTask_PlayStun이 자동으로 처리

  Beaten은 짧은 즉각 반응이라 BT를 통하지 않고 직접 호출해도 무방하고, Stun/Death처럼 BT 흐름을 장시간 점유하는 것만 BB키로 제어하면 됩니다.
