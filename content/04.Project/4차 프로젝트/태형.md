빌드 후 실행시 에디터가 켜지지 않는 문제 발생  
원인 분석  
C++ 클래스 생성자에서 FclassFinder를 사용해 애니메이션 블루프린트를 찾는데, 그 애니메이션 블루프린트 내부 노드에 Cast to WOMCharacterBow가 있었다.  
WOMCharacterBow는 CharacterBase를 상속하기 때문에 애니메이션블루프린트가 로드될때 까지 기다립니다.  
하지만 애니메이션 블루 프린트는 클래스 정보가 확정되기 전까지 컴파일을 안하는 데드락 에 빠지기 때문에 에디터가 실행이 안되고 멈추는 프리징 현상이 발생 했습니다.  
해결  
과감하게 애니메이션 블루프린트에서 Cast to WOMCharacterBow를 제거하고 Pawn Control을 받아와서 데드락을 피해주는 방법으로 해결 했다

화살 생성시 각도가 이상함  
원인 분석  
Arrow가 CharacterBow의 오른손 소켓 위치에서 생성이 되는데 생성과 동시에 character와 충돌 판정이 나기 때문에 튕겨서 각도가 이상해졌음  
해결  
Arrow.cpp 속 beginplay에서 AWOMCharacter와의 충돌판정을 꺼줌  
새로운 문제  
여러 화살을 동시에 소환시 화살끼리 서로 겹쳐서 엉뚱한 방향으로 날아감  
에디터 설정을 통해 Arrow ObjectChannel을 지정하고 Arrow끼리 collision을 Ignore하게 바꿔줬는데도 여전히 서로 겹치는 문제 발생  
원인 분석

해결

플레이어가 화살에 맞는 현상  
원인 분석  
화살 생성시 beginplay에서 플레이어를 받아와서 ignoreActorWhenMoving으로 무시를 해줬는데 플레이어와 충돌 처리가 됨  
아마 생성될때 플레이어의 콜리전과 겹쳐서 스폰이 되기 때문에 무시 처리가 되기전 hit이벤트가 트리거 되는것으로 보임  
생성자에서 처리를 하려 했으나 생성자가 호출되는 시점에서는 Character를 받아 올수 없음  
해결  
새로운 objectchannel을 만들어서 player는 해당 채널 속성을 갖고, Arrow는 해당채널을 무시하게 처리함  
  
피격 애니메이션 발생시 state가 고정되는 현상  
원인 분석  
현재 애니메이션 처리가  
입력 들어옴→ State변경 → State에 해당하는 애니메이션 재생 → 애니메이션 끝나기전에 입력 들어온거 버퍼에 저장 → 애니메이션 끝나면 입력이 유효한지 확인 → 유효한 입력이면 다음 State로 변경  
으로 처리하는데 애니메이션 끝나기 전에 피격 애니메이션이 들어와서 애니메이션 끝날때 처리를 못한채로 다른 애니메이션이 실행 됐기 때문에 해당 현상이 발생함  
해결  
히트시 명시적으로 기본 상태로 돌아오게 바꿈  
  
회피시 Collision을 QueryOnly로 바꿔도 피격 처리 되는 현상  
원인 분석  
QueryOnly는 몸비비기 같은 물리적인 처리만 통과할뿐 LineTrace나 Ovrlap처리는 진행하는 상태라 lineTrace로 구현된 공격은 맞음  
해결  
CharacterBase에 무적중인지 나타내는 변수를 두고 회피 시작시 무적 true, 끝날시 무적 false로 바뀌게 한뒤, 데미지처리, 피격처리 함수에서 처음에 무적이면 return으로 나오게 처리함
