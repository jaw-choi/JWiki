공격  
• FSM을 통한 콤보 공격 구상(Idle을 제외한 모든 노드에서 Idle로 이동 가능)  
  
• 전이 조건을 좌클릭 / 우클릭으로 정하고 State의 이름을 통해 상태 전이  
콤보 그래프 TMap에서 키 : State이름 / 값 : 콤보 노드 데이터  
콤보 노드 데이터 : 현 상태에 재생할 애니메이션 몽타주 / 이 상태에서 전이 가능한 트랜지션 데이터  
트랜지션 데이터 : 전이할 입력 (좌클릭 / 우클릭) / 다음 상태  
  
공격이 실행되는 로직  

1. Idle상태에서 입력시 ComboActionBegin 함수 호출
2. Idle 상태의 FComboNodeData에서 입력한 전이 상태가 있는지 확인 → 존재시 해당 상태로 전이 및 ExecuteComboState 호출
3. ExecuteComboState 함수에서 현재 상태에 FComboNodeData에 입력한 애니메이션 몽타주 재생 및 몽타주 종료 델리게이트에 ComboActionEnd 함수 바인드 및 타이머 설정
4. 타이머에 현재 상태에 맞는 입력 대기시간 타이머 설정 후 ComboCheck 함수 바인드
5. 애니메이션 재생중에 공격 입력시 입력값 저장
6. 타이머 종료시 ComboCheck 함수 실행, 콤보 도중에 입력한 값이 없다면 몽타주가 끝까지 재생되며 몽타주 종료 델리게이트 실행 및 ComboActionEnd 함수 호출, 콤보 중 입력이 없거나, 현 상태에서 입력에 대한 전이가 없을때 Idle 상태로 초기화 / 입력한 값이 존재한다면, 해당 입력에 대한 전이 존재시에 다시 ExecuteComboState 함수 실행하며 3번 반복

  
  
상호작용  

- 특정 액터가 상호작용 가능한지 판단하는 인터페이스 추가
- 플레이어가 가진 Trigger 진입시 상호작용 인터페이스를 구현한 액터를 배열에 저장하고 UI를 띄움
- 플레이어가 F키 입력시 현재 상호작용 가능한 액터 배열에서 거리값과 카메라와의 각도값을 통해 상호작용할 액터 선별하고 사용

  
  
패링시 시간이 느려지는 효과 추가  

- 패링 성공 애니메이션 재생시 시간 느리게 가는 효과 추가
- 게임 인스턴스에서 레벨 로드 시 BP_TimelineManager 액터 스폰
- 해당 액터에서 Timeline을 통해 시간을 느리게 가는 이벤트 추가
- 패링 성공 애니메이션에서 Notify 발동시 타임라인 매니저를 찾고, 해당 이벤트 호출하여 구현
- 패링 범위를 방패 매쉬에서 캐릭터 정면 정사각형으로 변경
- 피격 카메라 쉐이크 수치 조정
- 월드에 스폰되는 캐릭터 액터를 BP로 설정, 각 캐릭터 별로 BP 액터 생성 완료
- 프로젝트 세팅에서 게임 인스턴스를 WOMGameInstance로 변경

트러블 슈팅  

- 패링의 시간 느려짐 효과를 주기위해 검방패 캐릭터의 BP를 제작, ANS또한 BP로 만들고 패링 몽타주에 ANS를 배치함. 패링에 효과가 적용된 것을 확인하고 에디터를 껏다가 다시 키니 에디터가 73%에서 무한 로딩이 걸림 (Compiling blueprint)
- 디버깅을 해보니 플레이어의 생성자에서 콤보 애셋 데이터를 로드하는데, 해당 콤보 애셋 데이터에 패링 몽타주가 있고, 해당 몽타주에 ans에서 다시 플레이어를 향하는 순환 구조가 원인으로 추측
- 시간 느려지는 효과를 주는 이벤트를 게임모드에 배치해보았지만 게임모드에서도 Default Pawn Class에서 플레이어를 가지고 있어서 문제가 지속됨
- 결국 타임라인 이벤트를 관리할 BP_TimlineManager 객체를 만들고 게임 인스턴스에서 레벨 로드가 완료되면 자동으로 스폰하게 설정하여 해결함
