## Day2 계획 정리 및 개선 방향

### 1. 계획 요약

- 트레일러 효과 구현
- 파티클 효과 구현
- 맵 사이드 충돌 시 게임 오버 처리
- 눈덩이 위치 조정
- 재시작 시 Segment 초기화 (y=0부터 정렬)

### 2. 개선 방향 및 성능 최적화

#### 트레일러 효과 구현

- **구현 방법:** `TrailRenderer` 컴포넌트 사용
- **성능 최적화:**
  - 트레일 길이를 적절하게 조절하여 과도한 파티클 생성을 방지합니다.
  - `time` 변수를 조절하여 트레일 길이를 최적화합니다.
  - 필요에 따라 `emitting`을 조절하여 트레일 생성을 제어합니다.

#### 파티클 효과 구현

- **구현 방법:** `ParticleSystem` 컴포넌트 사용
- **성능 최적화:**
  - 파티클 개수를 제한하여 과도한 오버드로우를 방지합니다.
  - 파티클 크기, 속도, 수명 등을 최적화합니다.
  - 셰이더를 사용하여 파티클 렌더링 성능을 향상시킵니다.
  - Object Pooling을 사용하여 파티클 시스템을 재사용합니다.

#### 맵 사이드 충돌 시 게임 오버 처리

- **구현 방법:**
  - 맵 사이드에 Collider를 추가합니다.
  - 플레이어에 Collider와 Rigidbody를 추가합니다.
  - `OnCollisionEnter` 또는 `OnTriggerEnter` 함수를 사용하여 충돌을 감지합니다.
  - 충돌 발생 시 게임 오버 로직을 실행합니다.
- **성능 최적화:**
  - 불필요한 물리 연산을 줄이기 위해 Collider의 `isTrigger` 속성을 활용합니다.
  - 충돌 감지 로직을 최소화합니다.

#### 눈덩이 위치 조정

- **구현 방법:**
  - 플레이어 오브젝트의 위치를 기준으로 눈덩이의 위치를 조정합니다.
  - `Transform.position`을 사용하여 눈덩이의 위치를 설정합니다.
- **성능 최적화:**
  - Update() 함수 내에서 불필요한 계산을 줄입니다.
  - 필요에 따라 Coroutine을 사용하여 위치 조정 작업을 분산합니다.

#### 재시작 시 Segment 초기화 (y=0부터 정렬)

- **구현 방법:**
  - 재시작 시 Segment들을 y=0 위치에 재배치합니다.
  - Segment들을 순서대로 정렬합니다.
- **성능 최적화:**
  - 초기화 로직을 최적화하여 재시작 시간을 단축합니다.
  - Object Pooling을 사용하여 Segment를 재사용합니다.

### 3. 추가 고려 사항

- **UI:** 게임 오버 UI, 점수 UI, 재시작 버튼 등을 구현합니다.
- **사운드:** 배경 음악, 효과음 등을 추가하여 게임의 몰입도를 높입니다.
- **테스트:** 다양한 환경에서 게임을 테스트하여 버그를 수정하고 최적화합니다.
