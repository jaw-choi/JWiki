- 같은 상속 계층에 속한 타입끼리 , 런타임에 타입검사
				- 업캐스팅된 포인터에 대해서 다시 다운캐스팅할때 성공 
				- 포인터에 대해서는 실패시(타입이 다를 시) nullptr 반환
				- 레퍼런스에 대해서는 std::bad_cast예외 발생 => 레퍼런스 다이나믹캐스팅은 느려서 잘 안씀
				- dynamic_cast 를 쓰려면 vtable이 필요하다 즉, 가상함수가 필요함
				- ==포인터 타입의 형변환을 할 때는 “다운 캐스팅”에 항상 주의==
				- 예전엔 RTTI 문자열 비교->느림
				- 요즘엔 컴파일러/플랫폼에 따라 다름->빨라졌음
			    - 상속 계층에서 런타임 타입 검사(RTTI) 기반 안전한 다운캐스팅.
			    - 동작 조건: 대상 타입이 다형적(polymorphic)이어야 함=>virtual 함수가 있어야한다는말
			    - =>vtable이 있어야 한다는말
			    - (보통 가상 함수가 최소 1개 필요 → vtable/RTTI 활용).

실시간 성능 (Performance): 표준 dynamic_cast는 런타임에 타입 안전성을 확인하기 위해 내부적으로 복잡한
      문자열 비교나 타입 트리 탐색을 수행하므로, 프레임 단위로 수천 번 호출될 수 있는 게임 엔진(예: 충돌 처리,
      액터 타입 분류)에서는 오버헤드가 큽니다. 커스텀 RTTI는 정수(ID) 비교나 단순 포인터 비교로 이를 대체하여
      훨씬 빠릅니다.
