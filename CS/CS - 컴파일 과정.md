## 1. 한 줄 요약
컴파일 과정은 소스 코드를 실행 가능한 형태로 변환하는 과정으로, 전처리, 컴파일, 어셈블, 링크 단계를 거친다.

## 2. 왜 필요한가? (Why)
- 소스 코드를 컴퓨터가 이해할 수 있는 기계어로 변환
- 프로그램 실행 가능하도록 만듦
- 최적화 및 오류 검사 수행

## 3. 핵심 개념 (What)
1.  전처리: `#include`, 매크로 확장, 주석 제거
2.  컴파일: 소스 코드를 어셈블리어로 변환
3.  어셈블: 어셈블리어 코드를 기계어로 변환
4.  링크: 목적 파일들을 결합하여 실행 파일 생성

## 4. 동작 과정 (How)
- 각 단계별로 특정 도구 (전처리기, 컴파일러, 어셈블러, 링커) 사용

## 5. 장단점 / 트레이드오프
- 각 단계별 최적화를 통해 성능 향상 가능
- 복잡한 과정으로 인해 빌드 시간 증가 가능성

## 6. 자주 나오는 질문 / 오해
- Q: 링커는 왜 필요한가?
- A: 여러 개의 목적 파일을 하나로 묶고, 외부 참조를 해결하기 위해 필요

## 7. 프로젝트에서 어디에 쓰일 수 있는가
- 게임 엔진 빌드
- 라이브러리 생성
- 실행 파일 생성
