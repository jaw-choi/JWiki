## 1. 한 줄 요약

프로그램의 메모리는 크게 스택, 힙, 데이터, 코드 영역으로 나뉘며, 각 영역은 서로 다른 용도로 사용된다.

## 2. 왜 필요한가? (Why)

- 메모리 구조를 이해하면 프로그램의 동작 방식과 성능을 최적화하는 데 도움이 된다.
- 각 영역의 특징을 알면 메모리 관련 오류를 쉽게 해결할 수 있다.
- 메모리 관리는 게임 개발에서 매우 중요한 요소이므로, 메모리 구조에 대한 이해는 필수적이다.

## 3. 핵심 개념 (What)

- **스택(Stack):** 함수 호출과 관련된 지역 변수, 매개변수, 반환 주소 등이 저장되는 영역. LIFO(Last-In-First-Out) 구조를 가진다.
- **힙(Heap):** 동적으로 할당되는 메모리가 저장되는 영역. `new` 연산자를 통해 할당된 메모리는 힙에 저장된다.
- **데이터 영역:** 전역 변수, 정적 변수 등이 저장되는 영역. 프로그램 시작 시 할당되어 종료 시 해제된다.
- **코드 영역:** 실행할 프로그램의 코드가 저장되는 영역.

## 4. 동작 과정 (How)

1. 함수가 호출되면 스택에 새로운 프레임이 생성된다.
2. 프레임에는 지역 변수, 매개변수, 반환 주소 등이 저장된다.
3. 함수가 종료되면 스택에서 해당 프레임이 제거된다.
4. `new` 연산자를 통해 힙에 메모리가 할당된다.
5. `delete` 연산자를 통해 힙에 할당된 메모리가 해제된다.
6. 전역 변수와 정적 변수는 프로그램 시작 시 데이터 영역에 할당된다.
7. 실행할 프로그램의 코드는 코드 영역에 저장된다.

## 5. 장단점 / 트레이드오프

- 스택:
    - 장점: 빠른 접근 속도, 자동 메모리 관리
    - 단점: 크기 제한, 동적 할당 불가능
- 힙:
    - 장점: 동적 할당 가능, 크기 제한 없음
    - 단점: 느린 접근 속도, 수동 메모리 관리 필요
- 데이터 영역:
    - 장점: 프로그램 전체에서 접근 가능
    - 단점: 메모리 낭비 가능성, 초기화 순서 중요
- 코드 영역:
    - 장점: 실행 코드 저장
    - 단점: 수정 불가능

## 6. 자주 나오는 질문 / 오해

- Q: 스택과 힙의 차이점은 무엇인가요?
- A: 스택은 함수 호출과 관련된 데이터를 저장하는 영역으로, LIFO 구조를 가지며 빠른 접근 속도를 제공합니다. 힙은 동적으로 할당되는 메모리를 저장하는 영역으로, 크기 제한이 없지만 스택과 비교했을때 상대적 느린 접근 속도를 가집니다.
