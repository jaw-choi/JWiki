## 1. 한 줄 요약
정렬 알고리즘은 데이터를 특정 순서대로 재배열하는 알고리즘으로, 효율적인 데이터 검색 및 관리에 필수적이다.

## 2. 왜 필요한가? (Why)
- 데이터 검색 속도 향상
- 데이터 분석 및 시각화 용이
- 효율적인 데이터 관리

## 3. 핵심 개념 (What)
- 버블 정렬, 선택 정렬, 삽입 정렬, 퀵 정렬, 병합 정렬, 힙 정렬 등 다양한 알고리즘 존재
- 각 알고리즘은 시간 복잡도와 공간 복잡도 측면에서 트레이드오프 존재

## 4. 동작 과정 (How)
- 각 알고리즘마다 고유한 정렬 방식 사용 (비교, 교환, 분할 등)

## 5. 장단점 / 트레이드오프
- 버블, 선택, 삽입 정렬: 구현 간단, 작은 데이터셋에 적합 (O(n^2))
- 퀵, 병합, 힙 정렬: 큰 데이터셋에 적합 (O(n log n)), 추가 공간 필요

## 6. 자주 나오는 질문 / 오해
- Q: 어떤 정렬 알고리즘을 선택해야 하는가?
- A: 데이터셋 크기, 분포, 메모리 제약 등을 고려하여 선택

## 7. 프로젝트에서 어디에 쓰일 수 있는가
- 게임 오브젝트의 우선순위 정렬
- 리더보드 구현
- 검색 결과 정렬

# 면접 질문
Vector와 List에 각각 가장 알맞은 정렬 알고리즘은 어떤 것이라 생각하나요?
 - 벡터의 특성은 메모리가 연속적으로 위치하여 있습니다.이러한 특성을 고려하면 Vector는 인트로소트(퀵+힙+삽입정렬)알맞고 .
	 - 퀵: pivot선정, 파티션 배치 O(nlogn ~ n^2)
	 - 힙: 정렬된 이진트리를 만드는과정, O(nlogn)
	 - 삽입: 값을 하나 뽑아서 정렬된 구간에 끼워 넣는 방식 O(n ~ n^2)
 -  List는 포인터로 다음 저장소를 가르키는 형태로 되어 있습니다.  List는 머지소트가 가장 알맞습니다. 랜덤 액세스가 느리기 때문이고, 반으로 나누고 합치는 과정의 비용이 적기 때문입니다.
 - 머지소트 : 구간을 최소까지 나누고 이후 각 구간을 병합하면서 정렬, O(nlogn)
