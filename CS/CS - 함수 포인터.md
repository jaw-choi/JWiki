

## 1. 한 줄 요약

함수 포인터는 함수의 주소를 저장하는 변수로, 콜백 함수 구현에 주로 사용된다.

## 2. 왜 필요한가? (Why)

- 콜백 함수 구현
- 함수를 인자로 전달
- 유연한 코드 설계

## 3. 핵심 개념 (What)

- 함수 포인터: 함수의 주소를 저장하는 변수
- 콜백 함수: 시스템 또는 다른 함수에 의해 호출되는 함수
- `delegate`: 함수 포인터의 객체 지향적인 표현 (C# 등)

## 4. 동작 과정 (How)

1. 함수 포인터 변수 선언
2. 함수 주소를 함수 포인터에 할당
3. 함수 포인터를 통해 함수 호출

## 5. 장단점 / 트레이드오프

- 장점:
    - 유연한 코드 설계 가능
    - 콜백 함수 구현 용이
- 단점:
    - 코드 가독성 저하 가능성
    - 타입 안전성 문제 발생 가능성

## 6. 자주 나오는 질문 / 오해

- Q: 함수 포인터는 왜 사용하는가?
- A: 콜백 함수 구현, 함수를 인자로 전달, 유연한 코드 설계

## 7. 프로젝트에서 어디에 쓰일 수 있는가

- 이벤트 처리
- GUI 프로그래밍
- 게임 엔진
