### 사람인 이력서 자기소개서 (자유 양식, 1,000자 기준)
*(934자 / 제한 1000자)*

LangGraph와 LangChain으로 만든 에이전트를 공공기관과 기업의 실제 업무에 들이는 일에 참여하고 싶어 지원했습니다. 공고에서 'RAG나 LLM 애플리케이션을 한 번이라도 직접 만들어 본 경험'을 묻는데, 저는 SeSAC 과정에서 직접 만든 AI 비서로 그 질문에 답할 수 있습니다. SeSAC AI 서비스·클라우드 과정 팀 프로젝트로 Windows용 개인 AI 비서를 개발하며 에이전트와 음성 인식을 맡았습니다. 19개 도구와 69개 평가 문장을 직접 정의해 명령 분류 방식을 비교하니 규칙만 쓰면 정확도 78%, LLM만 쓰면 88%였지만 LLM은 느리고 토큰 비용이 컸습니다. 그래서 명확한 명령은 규칙 라우터가 처리하고 애매한 문장만 LLM에 넘기는 하이브리드 구조로 바꿨고, 정확도 91%를 유지하면서 LLM 단독 대비 처리 시간과 토큰 사용량을 약 60% 줄였습니다. 또 위험한 작업 앞에서는 사용자에게 확인을 받도록 정책을 바꿨는데, 이는 공고의 가드레일 설계와 같은 고민이라고 생각합니다. 또 팀원의 OS 제어 코드를 고치지 않도록 어댑터를 두어 실행 결과를 success/failed/rejected로 정규화했고, request_id로 음성 요청부터 실제 실행까지 추적할 수 있게 했습니다. 지금은 RAG 파이프라인과 FastAPI 서버, LangGraph 기반 워크플로우를 익히고 있고, 과정 후반에는 Kubernetes 기반 배포까지 배웁니다. 미국 A Round Entertainment에서 소프트웨어 엔지니어 인턴으로 App Store에 출시된 데이팅 앱 JOOPI의 프로필 편집, 이미지 업로드·순서 변경, Firebase 실시간 동기화를 React Native로 구현했습니다. 새로운 기법을 문서와 예제로 직접 구현해 보는 것을 즐기는 만큼, PoC를 빠르게 만들고 측정 가능한 기준으로 프로덕션까지 끌고 가는 개발자가 되겠습니다.
