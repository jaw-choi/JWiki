### 퀵 정렬의 기본 원리

- **분할 정복 알고리즘**  
    전체 배열을 하나의 기준점(피벗)으로 나누고, 나눈 두 영역을 재귀적으로 정렬 → 전체 배열이 정렬됨.
    
- **작은 단위부터 처리**  
    배열을 점점 작은 하위 배열로 나누어 정렬 속도를 높임.
    
- **평균 성능**  
    대부분의 경우 `O(n log n)`으로 매우 빠름.
    

---

### 피벗 선택 전략

- 퀵 정렬 성능의 핵심은 **피벗 선택**
    
- **좋은 피벗** → 전체 배열을 거의 균등하게 나눌 수 있는 값
    
    - 이상적으로는 **중간값**
        
    - 구현상 부담이 있으므로, 흔히 쓰는 방법:
        
        1. 첫 번째 요소 선택 (간단하지만 최악의 경우 가능)
            
        2. 세 요소 중 중간값 선택 → 최악은 반드시 회피
            
        3. 무작위 선택 → 평균 성능은 좋지만 랜덤 연산 비용 있음
            
- **최악 상황**  
    배열이 이미 정렬되어 있거나, 가장 큰/작은 값을 피벗으로 계속 선택할 때 발생
    

---

### 분할(Partition) 방법

- **인덱스 두 개 사용**
    
    - `left` → 왼쪽에서 오른쪽으로 이동
        
    - `right` → 오른쪽에서 왼쪽으로 이동
        
- **루프 조건**: `left <= right`
    
- **분할 과정**
    
    1. `left`가 피벗보다 큰 값을 만날 때까지 이동
        
    2. `right`가 피벗보다 작은 값을 만날 때까지 이동
        
    3. 두 값 교환 → 계속 반복
        
    4. `left`와 `right`가 교차하면 루프 종료
        
- **마지막 단계**
    
    - 피벗과 `right` 위치의 값을 교환 → 피벗이 정확한 위치에 들어감
        
    - 반환값: 피벗의 최종 인덱스 (`right`)
        

---

###  재귀 호출

- **왼쪽 서브배열** → 시작 인덱스 ~ 피벗-1
    
- **오른쪽 서브배열** → 피벗+1 ~ 끝 인덱스
    
- 각 서브배열에 대해 같은 파티션 수행 → 재귀적으로 정렬
