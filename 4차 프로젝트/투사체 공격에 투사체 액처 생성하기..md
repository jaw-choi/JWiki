P_ToadProjectile 블루프린트 생성 순서                                                                                                                                
                                                                                                                                                                      
  1. 블루프린트 생성                                                                                                                                                    
  - Content Browser → Monster/NormalMonster/MonsterToad/ 폴더
  - 우클릭 → Blueprint Class                                                                                                                                            
  - 검색창에 WOMToadProjectile 입력 → 선택                  
  - 이름: BP_ToadProjectile

  2. 시각적 메시 추가
  - BP_ToadProjectile 열기 → Viewport 탭
  - + Add → Static Mesh Component 추가
  - Details → Static Mesh에 원하는 구체/불덩이 메시 할당
  - Transform으로 크기/위치 조정

  3. 충돌 구 크기 확인
  - Components 패널에서 SphereComp 선택
  - Details → Shape → Sphere Radius (기본 20.0) 메시에 맞게 조정

  4. BP_ToadMonster에 할당
  - BP_ToadMonster 열기
  - Details → Combat → ProjectileClass → BP_ToadProjectile 선택
  - ProjectileDamage, ProjectileArcParam 값 조정

  5. AttackMontage에 노티파이 추가
  - AttackMontage 열기 → Fire 섹션
  - 투사체가 발사되는 타이밍 프레임에 우클릭 → Add Notify → AN_SpawnFireProjectile
  - 노티파이 선택 → Details → MouthSocketName = MouthSocket

  6. 스켈레톤에 MouthSocket 추가 (아직 안 됐다면)
  - Giang_99_Skeleton 열기
  - Skeleton 탭에서 입 근처 뼈 선택 → 우클릭 → Add Socket
  - 이름: MouthSocket → Preview 메시로 위치 조정 → 저장
