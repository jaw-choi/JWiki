## 작성 글
### 자유 양식 자기소개 (이력서 요약, 커버레터용)
*(924자 / 제한 1000자)*

업무를 대신 처리하는 에이전트가 실제로 믿을 만한지 확인하고 고치는 일을 가장 잘할 수 있다고 생각해 AI Data Engineer Internship에 지원합니다. SeSAC AI 서비스 클라우드 과정 팀 프로젝트에서 Windows용 AI 비서의 에이전트와 음성 부분을 맡아, 사용자의 말을 19개 도구 중 하나로 연결하는 tool calling 구조를 만들었습니다. 처음에는 LLM 응답이 그럴듯해 보여 잘 동작한다고 생각했지만, 69개의 평가 문장을 직접 만들고 실패 사례를 모아 보니 비슷한 명령을 다른 도구로 보내는 경우가 반복되었습니다. 그래서 실패 문장을 유형별로 나누어 규칙으로 처리할 명령과 LLM에 맡길 명령을 구분했고, 규칙 78%, LLM 88%였던 정확도를 하이브리드 구조에서 91%까지 올리면서 처리 시간과 토큰 사용량은 LLM 단독 대비 약 60% 줄였습니다. 이 경험으로 프롬프트를 고치기 전에 로그와 평가 결과부터 확인하는 습관이 생겼습니다. 또 팀원의 명령 API에 붙는 클라이언트를 맡아 로그인, 토큰 만료 시 재로그인, 상태 조회를 구현했고, 팀 테스트 47개가 통과하는 것을 확인한 뒤 PR로 병합했습니다. 미국 A Round Entertainment 인턴 시절에는 출시 앱 JOOPI에서 Firebase 실시간 동기화를 구현하며 외부 시스템과 데이터를 안전하게 맞추는 일을 경험했습니다. 우대사항에 있는 LLM API, AI agent, tool calling, workflow automation을 모두 실제 프로젝트에서 다뤄 본 만큼, 에이전트 실행 로그와 실패 케이스 분석에 처음부터 기여할 수 있습니다. Docker와 Kubernetes는 과정 후반에 배우고 있어, 컨테이너 기반 에이전트 실행 환경도 빠르게 익히겠습니다. 구성원의 반복 업무를 실제로 줄여 주는 AI 업무 도우미를 함께 고도화하겠습니다.
