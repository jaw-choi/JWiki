## 작성 글
### 자유 양식 자기소개 (이력서 요약, 커버레터용)
*(878자 / 제한 1000자)*

영문 금융 문서처럼 길고 정확해야 하는 자료를 AI가 다루기 쉬운 형태로 바꾸는 일에 기여하고 싶어 Software Engineer Internship에 지원합니다. 저는 미국 DigiPen에서 컴퓨터공학 학사 과정을 마쳤고, 수업과 팀 프로젝트를 모두 영어로 진행하며 기술 문서를 읽고 정리하는 일에 익숙해졌습니다. 최근 OPIc AL을 취득했고, 미국 A Round Entertainment에서 원격 인턴으로 일하며 영어로 요구사항을 확인하고 출시 앱 JOOPI의 프로필 편집과 Firebase 실시간 동기화를 구현했습니다. 데이터 쪽에서는 ADsP와 정보처리기사를 취득하며 데이터 해석과 소프트웨어 공학의 기본을 다졌습니다. 현재 SeSAC AI 서비스 클라우드 과정에서 LLM, RAG, LangChain, FastAPI를 배우고 있는데, RAG를 다루며 문서를 어떻게 나누고 어떤 근거를 붙이느냐에 따라 답변 품질이 크게 달라진다는 것을 체감했습니다. 팀 프로젝트인 AI 비서에서는 69개의 평가 문장을 직접 만들어 규칙, LLM, 하이브리드 방식을 비교했고, 하이브리드 구조로 정확도 91%를 얻으면서 처리 시간과 토큰을 약 60% 줄였습니다. 감으로 판단하지 않고 평가 데이터를 먼저 만드는 이 방식은 공시 자료처럼 근거가 분명해야 하는 금융 문서 처리에도 그대로 쓸 수 있다고 생각합니다. 예를 들어 공시 문서의 표와 본문을 나누어 저장하고, 답변마다 원문 위치를 함께 남겨 검증하기 쉽게 만드는 방식부터 시도해 보고 싶습니다. 재무제표와 회계 용어는 아직 기초 수준이지만, 인턴 기간 동안 공시 원문을 직접 읽으며 빠르게 익히겠습니다. Linux와 Git 기반 협업에 익숙하며, 맡은 데이터 처리 코드는 테스트와 문서까지 갖춰 넘기는 인턴이 되겠습니다.
