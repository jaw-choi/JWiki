## 작성 글
### 자유 양식 자기소개 (이력서 요약, 커버레터용)
*(885자 / 제한 1000자)*

LLM을 연구 결과로만 두지 않고 사람들이 매일 쓰는 서비스로 연결하는 엔지니어가 되고 싶어 NLP Research Engineer Internship에 지원합니다. 저는 SeSAC AI 서비스 클라우드 과정에서 LLM, RAG, LangChain과 LangGraph, MCP, FastAPI를 배우며 언어 모델을 API로 감싸 서비스에 붙이는 흐름을 익히고 있습니다. 팀 프로젝트인 AI 비서에서는 에이전트를 맡아 사용자의 문장을 19개 도구로 분류하는 문제를 다뤘는데, LLM 단독 방식은 정확도 88%로 좋았지만 응답이 느리고 토큰 비용이 컸습니다. 명확한 명령은 규칙으로, 애매한 문장만 LLM으로 보내는 구조로 바꿔 정확도 91%를 얻고 처리 시간과 토큰을 약 60% 줄이면서, 모델 성능만큼 서빙 비용과 지연 시간이 중요하다는 것을 배웠습니다. 또 팀원의 명령 API에 붙는 클라이언트를 맡아 로그인, 토큰 만료 시 재로그인, 상태 조회를 구현하며 서버와 클라이언트 사이의 약속을 맞추는 경험을 했습니다. 기본기는 컴퓨터공학 전공과 C++ 자체 엔진 개발에서 다졌습니다. 4인 팀 Project GGD에서 자체 엔진 JinEngine 위에 디펜스 게임의 게임플레이를 맡아 유닛 합성, 웨이브 스킵, 바이너리 저장을 구현했고, 개인 프로젝트에서는 쿼드트리 충돌 처리와 오브젝트 풀링으로 성능 문제를 풀었습니다. 이런 경험 덕분에 낯선 코드베이스를 읽고 병목을 찾는 일에 익숙합니다. HuggingFace Transformers를 이용한 학습 경험은 아직 깊지 않지만, 연구원분들의 실험 코드를 REST API 서비스로 옮기고 평가 파이프라인을 정리하는 일부터 성실히 맡겠습니다. 6개월 이상 풀타임 근무가 가능하며, 배운 것을 매일 기록하고 공유하며 빠르게 성장하겠습니다.
