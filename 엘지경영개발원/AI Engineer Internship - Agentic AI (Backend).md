### [예상] 지원 직무 관련 경험과 역량 (1,000자)
*(954자 / 제한 1000자)*

SeSAC AI 서비스·클라우드 과정 팀 프로젝트로 Windows용 개인 AI 비서를 개발하며 에이전트와 음성 인식을 맡았습니다. 19개 도구와 69개 평가 문장을 직접 정의해 명령 분류 방식을 비교하니 규칙만 쓰면 정확도 78%, LLM만 쓰면 88%였지만 LLM은 느리고 토큰 비용이 컸습니다. 그래서 명확한 명령은 규칙 라우터가 처리하고 애매한 문장만 LLM에 넘기는 하이브리드 구조로 바꿨고, 정확도 91%를 유지하면서 LLM 단독 대비 처리 시간과 토큰 사용량을 약 60% 줄였습니다. 서버 쪽에서는 팀원의 명령 API에 붙는 클라이언트를 맡아 개발 계정 로그인, 계정이 없을 때 자동 가입, 토큰 만료 시 재로그인을 구현했고, 설정 조회와 명령 상태 조회 API에 대응하는 구조를 만들었습니다. 변경 사항은 main 위에서 팀 테스트 47개 통과를 확인한 뒤 CI 오류를 고쳐 PR로 병합했고, 에이전트 지침과 작업 기록, 팀 공유 문서를 따로 정리해 다른 팀원이 제 모듈을 이해할 수 있게 했습니다. 컴퓨터공학 전공과 C++ 자체 엔진 개발로 자료구조와 성능의 기본기를 다졌고, AI 코딩 도구는 구조를 먼저 설계한 뒤 제가 설명할 수 있는 코드만 적용한다는 원칙으로 책임감 있게 사용합니다. 미국 A Round Entertainment에서 소프트웨어 엔지니어 인턴으로 App Store에 출시된 데이팅 앱 JOOPI의 프로필 편집, 이미지 업로드·순서 변경, Firebase 실시간 동기화를 React Native로 구현했습니다. 또 팀원의 OS 제어 코드를 고치지 않도록 어댑터를 두어 실행 결과를 success/failed/rejected로 정규화했고, request_id로 음성 요청부터 실제 실행까지 추적할 수 있게 했습니다. Docker와 Kubernetes는 과정 후반에 본격적으로 배우고 있어, 인턴 기간 동안 컨테이너 기반 배포와 GPU 자원 스케줄링까지 빠르게 익히겠습니다.
