# 2026-09-11 수업 정리

## 1. 전체 흐름

```text
내 컴퓨터
   ↓
네트워크 통신
   ↓
패킷 / 프로토콜
   ↓
HTTP
   ↓
HTML
   ↓
CSS + JavaScript
   ↓
CSV 데이터 연결
   ↓
웹 대시보드
   ↓
GitHub / Google Apps Script 등으로 배포
```

오늘 수업의 핵심은 단순히 HTML 문법을 배우는 것이 아니라, **내 PC에서 만들어진 데이터가 어떻게 네트워크를 통해 웹 화면으로 표현되고 다른 사람에게 공유되는지** 전체 과정을 이해하는 것이었다.

---

## 2. 네트워크: 데이터를 작은 조각으로 보낸다

인터넷에서는 큰 데이터를 그대로 보내는 것이 아니라 작은 단위인 **패킷(Packet)** 으로 나누어 전달한다.

```text
"안녕하세요"
      ↓
[조각1] [조각2] [조각3]
      ↓
   네트워크
      ↓
순서 확인 및 재조립
      ↓
"안녕하세요"
```

통신하는 컴퓨터들은 서로 동일한 규칙을 사용해야 하며, 이런 통신 규칙을 **프로토콜(Protocol)** 이라고 한다.

수업에서는 OSI 계층 개념과 연결하여 네트워크 통신이 여러 단계로 처리된다는 점도 다루었다.

### 대표적인 프로토콜

| 프로토콜 | 용도 |
|---|---|
| HTTP | 웹 데이터 통신 |
| FTP | 파일 전송 |
| SMTP | 이메일 전송 |

## 3. HTML: 웹페이지의 구조

**HTML = HyperText Markup Language**

브라우저에서 보여줄 문서의 **구조**를 만드는 언어이다.

### 기본 구조

```html
<html>
<head>
    <!-- 페이지 정보 -->
</head>

<body>
    <!-- 실제 화면에 보이는 내용 -->
</body>
</html>
```

### 주요 태그

| 태그 | 기능 |
|---|---|
| `<h1>` | 큰 제목 |
| `<h2>` | 작은 제목 |
| `<p>` | 문단 |
| `<br>` | 줄바꿈 |
| `<a>` | 링크 |
| `<li>` | 목록 |
| `<img>` | 이미지 |

예:

```html
<a href="https://www.google.com">구글 이동</a>
```

글자를 클릭하면 다른 사이트로 이동할 수 있다.

---

## 4. index.html

웹사이트 안에는 여러 HTML 파일이 존재할 수 있다.

```text
웹사이트
│
├─ index.html   ← 시작 페이지
├─ chrome.html
├─ excel.html
└─ help.html
```

보통 URL에 특정 HTML 파일을 지정하지 않았을 때 **index.html을 대표 시작 페이지로 사용하는 방식**을 배웠다.

---

## 5. CSS: 디자인을 담당한다

HTML이 구조라면 **CSS는 디자인**을 담당한다.

예를 들어 목록의 링크 글자를 모두 빨간색으로 만들고 싶다면 각각의 태그를 하나씩 수정하지 않고 스타일 규칙을 만들어 적용할 수 있다.

```css
li a {
    color: red;
}
```

### 역할 정리

```text
HTML = 구조
CSS  = 디자인
```

HTML 파일이 여러 개라면 각 HTML 안에 같은 스타일을 반복해서 쓰는 대신 **외부 `.css` 파일**로 분리할 수 있다.

---

## 6. JavaScript: 웹페이지에 동작을 넣는다

HTML 화면에 프로그램 같은 기능을 넣으려면 **JavaScript**를 사용할 수 있다.

예:

```text
버튼 클릭
   ↓
암호 입력
   ↓
암호 확인
   ↓
다른 HTML 페이지 이동
```

### 역할 정리

```text
HTML       → 구조
CSS        → 디자인
JavaScript → 동작
```

수업에서는 JavaScript와 연결하여 **Node.js를 이용하면 서버 측 기능까지 확장할 수 있다**는 개념도 소개했다.

## 7. 프론트엔드 / 백엔드 / 풀스택

### 프론트엔드

사용자 눈에 보이는 화면을 담당한다.

```text
HTML
CSS
JavaScript
```

### 백엔드

사용자에게 직접 보이지 않는 영역을 담당한다.

```text
서버
DB
사용자 처리
데이터 저장
네트워크 처리
```

### 풀스택

```text
프론트엔드 + 백엔드
```

프론트엔드와 백엔드 영역을 모두 이해하거나 다루는 개발자를 의미한다.

## 8. 시스템 모니터링 실습

오늘 수업에서 실제 프로젝트로 연결된 중요한 부분이다.

### 8.1 PC 정보 수집

Windows에서는 PowerShell을 이용하여 작업 관리자에서 볼 수 있는 시스템 정보를 가져올 수 있다.

예:

```text
시간
컴퓨터 이름
시스템 정보
CPU
Memory
실행 프로세스
Chrome
Explorer
OneDrive
...
```

### 8.2 CSV로 기록

실행할 때마다 데이터를 CSV 파일에 계속 추가할 수 있다.

```text
PowerShell
   ↓
PC 시스템 정보 수집
   ↓
CSV
```

예:

```csv
time,process,cpu,memory
13:28,chrome,20,512
13:28,explorer,10,220
13:42,chrome,25,530
```

PowerShell뿐 아니라 Python으로도 같은 작업을 할 수 있다.

## 9. CSV → HTML 대시보드

오늘 프로젝트의 핵심 흐름이다.

```text
작업 관리자
     ↓
PowerShell / Python
     ↓
CSV
     ↓
HTML
     ↓
Chart
     ↓
Dashboard
```

HTML 대시보드에는 다음과 같은 기능을 넣을 수 있다.

- CPU / Memory 차트
- 프로세스 순위
- 시간별 사용량
- 검색
- 필터
- 버튼
- 프로세스 선택
- 인터랙티브 차트

즉, **시스템 엔지니어가 수집한 데이터를 사람이 쉽게 볼 수 있도록 웹 화면으로 만드는 것**이다.

---

## 10. 로컬 파일과 서버 파일의 차이

내 HTML에서 다음처럼 내 컴퓨터의 파일 경로를 직접 사용하면:

```html
<img src="C:\images\dog.png">
```

내 컴퓨터에서는 보일 수 있지만 다른 사람의 컴퓨터에서는 볼 수 없다.

다른 사람이 보게 하려면 이미지 역시 공유 가능한 위치에 있어야 한다.

```text
내 PC 이미지
     ↓
서버 / 웹 저장소 업로드
     ↓
URL 생성
     ↓
HTML에서 URL 사용
```

웹사이트를 배포할 때는 HTML만 올리는 것이 아니라 필요한 **이미지, CSS, JavaScript 등의 파일도 같이 제공해야 한다.**

## 11. 캐시 개념

한 번 방문했던 사이트가 두 번째에는 더 빠르게 뜰 수 있는 이유 중 하나는 **로컬 임시 저장소에 이미 받아놓은 자료를 다시 활용하기 때문**이다.

### 첫 접속

```text
서버 → 이미지 다운로드 → PC 저장 → 표시
```

### 이후 접속

```text
PC에 저장된 데이터 → 표시
```

상황에 따라 서버에서 모든 자료를 다시 가져오지 않기 때문에 더 빠르게 표시될 수 있다.

## 12. 웹사이트를 다른 사람에게 보여주려면

내 PC에서 HTML을 직접 열면 다음과 같은 형태가 된다.

```text
file:///C:/test/index.html
```

이 상태는 기본적으로 내 컴퓨터에서 보는 로컬 파일이다.

다른 사람도 접속하게 만들려면 **웹 호스팅 또는 웹 서비스**가 필요하다.

수업에서는 예시로 다음 방법들을 언급했다.

```text
GitHub
Google Apps Script
Google Cloud 계열 서비스
기타 웹 서버
```

특히 **Google Apps Script를 이용하여 HTML을 웹앱 형태로 공개하는 방법**으로 이어지는 흐름을 설명했다.

# 핵심 정리 5가지

## 1. 인터넷 데이터는 네트워크 규칙에 따라 전달된다.

```text
데이터 → 패킷 → 네트워크 → 재조립
```

## 2. 웹 화면의 기본 구성

```text
HTML → 구조
CSS → 디자인
JavaScript → 기능
```

## 3. 시스템 데이터를 자동으로 수집할 수 있다.

```text
PowerShell / Python → CSV
```

## 4. 데이터를 웹 대시보드로 시각화할 수 있다.

```text
CSV → HTML → Chart → Dashboard
```

## 5. 다른 사람에게 보여주려면 서버에 배포해야 한다.

```text
내 PC
 ↓
웹 서버 / 클라우드
 ↓
URL
 ↓
다른 사용자
```
