# 4. Python 패키지 관리

현재 설치된 패키지를 저장:

```powershell
python -m pip freeze > requirements.txt
```

다른 환경에서 복구:

```powershell
python -m pip install -r requirements.txt
```

가상환경 폴더 자체를 복사하기보다는 다음 방법이 좋습니다.

```text
Python 설치
    ↓
새 가상환경 생성
    ↓
requirements.txt 설치
```

즉,

**requirements.txt = 프로젝트 실행에 필요한 패키지 목록**

이라고 이해하면 됩니다.

# 7. 정규표현식

정규표현식은 문자열에서 **원하는 패턴만 찾거나 제거하는 기술**입니다.

예:

```text
USERABC01
```

숫자만 찾기:

```python
import re

text = "USERABC01"

numbers = re.findall(r"\d+", text)

print(numbers)
```

결과:

```text
['01']
```

숫자가 아닌 문자를 제거:

```python
result = re.sub(r"\D", "", text)
```

결과:

```text
01
```

중요 표현:

```text
\d   숫자
\d+  연속된 숫자
\D   숫자가 아닌 문자
```

시스템 엔지니어는 이를 로그 분석 등에 사용할 수 있습니다.

```text
로그
↓
IP 추출
↓
ERROR 추출
↓
CPU 사용률 추출
↓
디스크 사용률 추출
```

# 8. 함수

함수는 **하나의 작업을 묶어 놓은 것**입니다.

```python
def get_user():
    return getpass.getuser()
```

사용:

```python
username = get_user()
```

함수를 사용하면 반복 코드를 줄이고 기능별 테스트와 재사용이 쉬워집니다.

매개변수:

```python
def repeat_text(text, count):
    print(text * count)
```

사용:

```python
repeat_text("-", 10)
```

결과:

```text
----------
```

# 9. 클래스

클래스는 서로 관련된 데이터와 기능을 묶어 관리할 때 사용합니다.

```python
class SystemInfo:

    def get_user(self):
        ...

    def get_ip(self):
        ...

    def get_os(self):
        ...
```

쉽게 생각하면:

```text
함수
= 하나의 기능

클래스
= 관련 기능을 묶어 놓은 구조
```

`self`는 현재 만들어진 객체 자신을 의미합니다.

```python
system = SystemInfo()

system.get_user()
```

# 11. 이미지의 기본 원리

이미지는 컴퓨터 내부에서 결국 **숫자의 배열**로 표현됩니다.

예를 들어 RGB 이미지에서는 한 픽셀이 다음과 같은 값을 가집니다.

```text
(R, G, B)
```

대표적인 색상:

```text
(0, 0, 0)
= 검정

(255, 0, 0)
= 빨강

(0, 255, 0)
= 초록

(255, 255, 255)
= 흰색
```

따라서 이미지 처리는 본질적으로

**숫자들을 변경하는 작업**

이라고 볼 수 있습니다.

이미지를 밝게 만든다면 픽셀 값에 숫자를 더하고, 어둡게 만든다면 숫자를 줄입니다.

단, 일반적인 8비트 이미지의 픽셀 값은:

```text
0 ~ 255
```

범위를 사용하므로 이를 벗어나지 않도록 처리해야 합니다.

# 12. 이미지 = 행렬

이미지는 다음과 같은 구조로 볼 수 있습니다.

```text
이미지
↓
행(Row)
↓
열(Column)
↓
픽셀
↓
RGB 숫자
```

따라서 이미지가 커지면 처리해야 할 숫자의 개수도 매우 많아집니다.

이것이 이미지 처리나 AI에서 CPU, 메모리, GPU 등의 시스템 자원 사용량이 중요한 이유 중 하나입니다.

# 13. Pillow

Pillow는 Python에서 이미지를 비교적 쉽게 다루기 위한 라이브러리입니다.

```python
from PIL import Image
```

이미지 열기:

```python
image = Image.open("fire.png")
```

정보 확인:

```python
print(image.size)
print(image.width)
print(image.height)
print(image.format)
print(image.mode)
```

크기 변경:

```python
resized = image.resize((640, 640))
```

회전:

```python
rotated = resized.rotate(90)
```

좌우 반전:

```python
flipped = rotated.transpose(
    Image.Transpose.FLIP_LEFT_RIGHT
)
```

자르기:

```python
cropped = flipped.crop(
    (100, 100, 500, 400)
)
```

흑백:

```python
gray = cropped.convert("L")
```

# 14. NumPy

NumPy는 이미지 데이터를 **숫자 배열로 직접 확인하고 처리할 때** 사용합니다.

```python
import numpy as np
```

Pillow 이미지를 NumPy 배열로 변환:

```python
data = np.array(gray)
```

확인:

```python
print(data)
print(data.shape)
```

특정 픽셀 값:

```python
print(data[100][200])
```

정리하면:

```text
Pillow
↓
이미지를 쉽게 불러오고 수정

NumPy
↓
이미지를 숫자 배열로 직접 처리
```

# 16. 차선 검출 실습

오늘 사용한 차선 검출 과정은 다음 흐름입니다.

```text
road.jpg
   ↓
이미지 읽기
   ↓
흑백 변환
   ↓
Gaussian Blur
   ↓
Canny Edge
   ↓
ROI 설정
   ↓
HoughLinesP
   ↓
차선 그리기
   ↓
원본 이미지와 합성
```

이미지 읽기:

```python
image = cv2.imread("road.jpg")
```

흑백:

```python
gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)
```

노이즈 제거:

```python
blur = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)
```

Edge 검출:

```python
edges = cv2.Canny(
    blur,
    50,
    150
)
```

직선 탐지:

```python
lines = cv2.HoughLinesP(
    roi,
    rho=1,
    theta=np.pi / 180,
    threshold=50,
    minLineLength=50,
    maxLineGap=100
)
```

즉 차선 인식은 AI만 사용하는 것이 아니라,

**전통적인 이미지 처리 + 수학적인 선 검출**

만으로도 기본적인 기능을 구현할 수 있습니다.


```text

↓
```

```text
↓
메모리 사용량
↓
디스크 사용량
↓
네트워크 사용량
```
