### [예상] 1. 지원 직무의 필수역량 중 강점 역량과 그 역량을 갖춘 과정

제 강점은 Python으로 기능을 만들고 외부 시스템과 연결하는 연계 개발 역량입니다. SeSAC 팀 프로젝트 AI 비서에서 에이전트를 맡아 19개 도구를 호출하는 구조를 Python으로 구현했고, 팀원이 만든 OS 제어 모듈과 로그인 API, Electron 화면이 같은 약속으로 통신하도록 인터페이스를 정리했습니다. 처음에는 모듈마다 입력과 출력 형식이 달라 통합할 때마다 오류가 났지만, 주고받는 데이터 형식을 먼저 문서로 맞춘 뒤 연결하자 통합 속도가 빨라졌습니다. 또한 Git 브랜치를 정리하며 여러 사람의 코드를 main에 합치는 과정도 맡았습니다. 미국 스타트업 원격 인턴에서는 Firebase 실시간 동기화로 앱과 서버 데이터를 연결해 본 경험도 있습니다. 현재 수준은 REST API와 데이터 연계를 직접 구현할 수 있는 단계이며, SeSAC 과정 후반에 Docker, Kubernetes, AWS를 배우며 클라우드 운영 역량을 더하고 있습니다.

> [확인 필요] 모듈마다 입출력 형식이 달라 통합 오류가 났다는 부분, 인터페이스를 문서로 맞췄다는 부분이 실제와 같은지 확인해 주세요.

### [예상] 2. AI나 디지털 툴로 한계를 극복하거나 효율을 높이고, 결과를 검증한 경험
*(436자 / 제한 500자)*

AI 비서 프로젝트에서 LLM의 결과를 그대로 믿지 않고 검증하는 체계를 만들었습니다. 19개 도구 중 어떤 도구를 부를지 LLM이 판단하게 했을 때 결과가 그럴듯해 보여도 실제로는 틀리는 경우가 있었습니다. 그래서 69개 평가 문장을 직접 만들고 같은 기준으로 규칙 기반, LLM 단독, 하이브리드 방식을 비교했습니다. 규칙 기반은 78%, LLM 단독은 88%였고, 틀린 문장을 하나씩 보며 두 방식이 약한 유형이 다르다는 점을 찾았습니다. 이 데이터를 근거로 명확한 명령은 규칙으로, 모호한 요청만 LLM으로 보내는 하이브리드 라우팅을 설계해 정확도 91%를 달성하고 처리 시간과 토큰을 약 60% 줄였습니다. AI의 결과는 전공 지식과 측정 기준으로 검증할 때 비로소 업무에 쓸 수 있다는 것을 배웠고, AWS Bedrock 기반 개발환경에서도 같은 원칙으로 일하겠습니다.

### [예상] 3. 도전적인 목표를 세우고 끈질기게 노력한 경험
*(442자 / 제한 500자)*

2인 팀으로 Unity 게임 눈덩이를 굴려라를 Google Play와 App Store에 직접 출시했습니다. 수업 과제가 아니라 실제 스토어에 출시하는 것이 목표였기 때문에, 게임을 완성하는 것보다 출시 과정이 더 어려웠습니다. UI Toolkit과 ScriptableObject로 화면과 데이터를 정리하고, Firebase와 AdMob을 연동하며 두 스토어의 서로 다른 심사 기준을 맞춰야 했습니다. 한 번에 통과하지 못하는 항목이 생길 때마다 원인을 기록하고, 반복되는 실수를 막기 위해 릴리즈 체크리스트를 만들어 매 빌드마다 점검했습니다. 그 결과 두 스토어 모두에 게임을 출시할 수 있었습니다. 끝까지 해내는 힘은 의지보다 같은 실수를 반복하지 않게 만드는 절차에서 나온다는 것을 배웠고, 이 습관은 클라우드 운영에서 장애를 줄이는 표준화 작업에도 그대로 쓰일 수 있다고 생각합니다.

> [확인 필요] 두 스토어 심사에서 통과하지 못한 항목이 있었다는 부분이 실제와 같은지 확인해 주세요.

### [예상] 4. 팀워크를 발휘해 사람들을 연결하고 공동 목표에 기여한 경험
*(454자 / 제한 500자)*

4인 팀 BIT SAVER에서 Tech Lead를 맡아 C++과 OpenGL 자체 엔진으로 리듬 게임을 만들었습니다. 프로그래머, 기획, 아트가 함께하는 팀이라 각자의 작업이 엔진 안에서 어떻게 만나는지 모두가 이해하는 것이 중요했습니다. 저는 FMOD로 MIDI 데이터를 파싱해 음악과 노트가 같은 시간 기준으로 움직이게 하는 구조를 만들고, 다른 팀원이 이 구조 위에서 콘텐츠를 추가할 수 있도록 사용 방법을 공유했습니다. 또 Arduino로 드럼 패드를 만들어 실제 입력 장치와 게임을 연결했는데, 하드웨어와 소프트웨어 담당이 같은 입력 형식을 쓰도록 맞추는 역할을 했습니다. 서로 다른 분야의 팀원이 같은 기준을 보게 되자 통합 오류가 줄었고 프로젝트를 끝까지 완성했습니다. 사람을 연결하는 것은 결국 일하는 기준을 공유하는 것이라 배웠고, 현업과 IT를 잇는 AI DT 조직에서도 이 역할을 하겠습니다.

> [확인 필요] BIT SAVER가 리듬 게임인지, 팀 구성(프로그래머, 기획, 아트)과 입력 형식을 맞춘 역할이 실제와 같은지 확인해 주세요.

### [예상] 5. 입사 후 이루고 싶은 성장 목표와 노력 계획
*(468자 / 제한 500자)*

입사 후 3년 안에 SK머티리얼즈의 AI 플랫폼을 안정적으로 운영하고, 현업이 AI Agent를 쉽게 만들 수 있는 개발환경을 책임지는 엔지니어가 되는 것이 목표입니다. 첫해에는 AWS 기반 인프라와 네트워크, 보안 환경을 정확히 익히고, 플랫폼 모니터링과 장애 분석을 맡아 운영 절차를 문서로 표준화하겠습니다. 이를 위해 SeSAC 과정 후반에 배우는 Docker, Kubernetes, AWS를 실습으로 다지고, Terraform 같은 IaC 도구와 AWS 자격증도 준비하겠습니다. 다음 단계에서는 AWS Bedrock과 MCP를 활용해 AI Agent 개발을 위한 API, Tool, 데이터 연계를 지원하고, 제가 AI 비서에서 해 본 것처럼 평가 기준을 함께 만들어 품질을 관리하겠습니다. 이후에는 클라우드 자원 사용량을 분석해 성능과 비용을 함께 최적화하며, 소재 현장의 문제를 AI로 푸는 과제가 빠르게 확산되도록 돕겠습니다.
