## 2025-12-28 작업 내용 상세 정리

- **새로운 에셋 적용:**
  - 게임의 시각적 퀄리티를 향상시키기 위해 새로운 에셋들을 프로젝트에 통합했습니다.
  - 에셋 스토어 또는 외부 리소스에서 다운로드한 모델, 텍스처, 스프라이트 등을 프로젝트에 추가했습니다.
  - 에셋들의 호환성을 확인하고, 필요한 경우 임포트 설정을 조정했습니다.

- **트레일러 효과 구현 작업:**
  - 플레이어 캐릭터 또는 특정 오브젝트에 트레일러 효과를 추가하여 움직임의 잔상을 표현했습니다.
  - `TrailRenderer` 컴포넌트를 사용하여 트레일러 효과를 구현하고, 트레일의 길이, 색상, 텍스처 등을 조정했습니다.
  - 트레일러 효과의 성능을 최적화하기 위해 파티클 개수 및 렌더링 설정을 조절했습니다.

- **장애물 배치 작업:**
  - 게임 레벨에 다양한 장애물들을 배치하여 게임의 난이도와 재미를 높였습니다.
  - 장애물의 종류, 크기, 위치, 간격 등을 고려하여 레벨 디자인을 구성했습니다.
  - 장애물들의 충돌 설정을 조정하여 플레이어와의 상호작용을 구현했습니다.

- **파티클 효과 구현 작업:**
  - 게임 내 다양한 상황에 맞는 파티클 효과를 추가하여 시각적인 풍성함을 더했습니다.
  - `ParticleSystem` 컴포넌트를 사용하여 폭발, 연기, 먼지, 눈 등의 파티클 효과를 구현했습니다.
  - 파티클의 개수, 크기, 속도, 색상, 수명 등을 조정하여 원하는 효과를 연출했습니다.
  - 파티클 효과의 성능을 최적화하기 위해 렌더링 설정 및 콜리전 설정을 조절했습니다.

- **맵 사이드 충돌 시 게임 오버 처리 구현:**
  - 플레이어가 맵의 경계를 벗어났을 때 게임 오버가 되도록 로직을 구현했습니다.
  - 맵의 양쪽에 Collider를 추가하고, 플레이어의 Collider가 맵의 Collider와 충돌했을 때 게임 오버 UI를 표시하거나 게임을 재시작하도록 설정했습니다.
  - `OnCollisionEnter` 또는 `OnTriggerEnter` 함수를 사용하여 충돌을 감지하고, 게임 오버 로직을 실행했습니다.

- **눈덩이 위치 조정 작업:**
  - 플레이어 캐릭터인 눈덩이의 위치를 적절하게 조정하여 게임 플레이 경험을 개선했습니다.
  - 눈덩이의 초기 위치, 이동 속도, 회전 등을 조정하여 자연스러운 움직임을 구현했습니다.
  - 카메라 시점에 맞춰 눈덩이의 위치를 조정하여 시각적인 만족도를 높였습니다.

- **재시작 시 Segment 초기화 (y=0부터 정렬) 구현:**
  - 게임을 재시작했을 때 맵을 구성하는 Segment들을 초기 상태로 되돌리는 로직을 구현했습니다.
  - Segment들의 위치를 y=0부터 시작하도록 재배치하고, 순서대로 정렬하여 일관된 게임 환경을 제공했습니다.
  - Segment들의 초기화 로직을 최적화하여 재시작 시간을 단축했습니다.

- **Figma에서 같은 장애물 이름 통일:**
  - Figma 디자인 파일에서 동일한 장애물에 대해 이름이 다르게 지정된 경우, 이름을 통일하여 관리의 효율성을 높였습니다.
  - 에셋 관리의 일관성을 유지하고, 개발 과정에서 혼동을 방지하기 위해 이름을 정리했습니다.

- **Figma에서 페이지 분류:**
  - Figma 디자인 파일의 페이지를 용도에 따라 분류하여 디자인 작업의 효율성을 높였습니다.
  - UI 디자인, 레벨 디자인, 에셋 디자인 등 각 페이지를 명확하게 구분하여 작업 공간을 정리했습니다.

- **Figma에서 이미지 레이어 순서 규칙 정의 (젤 큰 나무, 중간 나무, 작은 나무, 돌1, 돌2, 수풀 순):**
  - Figma 디자인 파일에서 이미지 레이어의 순서에 대한 규칙을 정의하여 디자인의 일관성을 유지했습니다.
  - 레이어 순서를 기준으로 에셋을 정렬하고, 개발 과정에서 발생할 수 있는 혼란을 줄였습니다.

- **레벨 디자인 맵과 실제 오브젝트의 SVG 파일 크기 맞춤:**
  - 레벨 디자인 맵과 실제 게임 오브젝트의 SVG 파일 크기를 일치시켜 디자인과 구현의 차이를 최소화했습니다.
  - 디자인 맵을 기준으로 오브젝트의 크기를 조정하여 정확한 레벨 디자인을 구현했습니다.

- **인게임 에셋 교체:**
  - 기존 에셋을 새로운 에셋으로 교체하여 게임의 시각적인 분위기를 변경하거나 개선했습니다.
  - 에셋의 종류, 크기, 텍스처 등을 변경하여 게임의 전체적인 스타일을 조정했습니다.

- **장애물 태그 명시:**
  - 게임 오브젝트인 장애물에 태그를 명시하여 스크립트에서 장애물을 쉽게 식별하고 제어할 수 있도록 했습니다.
  - 태그를 사용하여 장애물의 종류, 속성 등을 구분하고, 게임 로직에 활용했습니다.

  - 맵, 플레이어, 장애물 등의 오브젝트에 대해 Order In Layer 값을 설정하여 시각적인 깊이감을 표현했습니다.

  - Figma에서 디자인한 에셋을 Unity의 Sprite Renderer 및 Prefab으로 자동 변환하는 툴을 개발하여 작업 효율성을 높였습니다.
  - 툴을 사용하여 UI 디자인을 빠르게 게임에 적용하고, 반복적인 작업을 줄였습니다.
  - Figma API를 활용하여 디자인 데이터를 추출하고, Unity 에디터 스크립트를 사용하여 에셋을 생성했습니다.
